# moriguchi-denki

株式会社EL worksの家庭向け電気工事ホームページです。
大阪府守口市を拠点に、関西一円の照明・コンセント・配線・エアコン取り付け工事のご相談に対応します。

公開先: https://elworks20240911-design.github.io/moriguchi-denki/

## 構成
- `index.html`: 会社案内、対応工事、お問い合わせ
- `assets/hero.webp` / `assets/services.webp`: AIによるイメージ画像（施工実績ではありません）
- `sitemap.xml`: サイトマップ
- `.nojekyll`: 静的配信設定

GitHub Pagesのmainブランチ、ルートフォルダから配信する構成です。
お問い合わせにはFormspreeを使用しています。個人情報の取扱いはページ内の案内をご確認ください。
